### 🔬 Featured Open-Source Project

- **[SYNAPTIK](https://github.com/Fr4n0b/synaptik)** — Evidence-structure analysis and multi-class genomic reconciliation (literature mining, SpliceAI, gnomAD constraint, ClinVar, DepMap) for patient-derived iPSC-neuron research. Built to detect single-lab publication bias and resolve cross-layer contradictions before committing to wet-lab differentiation assays.

### 🛠️ Research & Technical Focus
- **Biological Systems**: Patient-derived human iPSC-derived neurons (NGN2 induction, dual-SMAD differentiation), synaptic phenotype assays (SYN1/PSD95 puncta quantification, mEPSC electrophysiology).
- **Computational Genomics**: Pre-mRNA alternative splicing, SpliceAI, nonsense-mediated decay (NMD), variant prioritization, CRISPR prime-editing pegRNA assay validation.
- **Languages & Frameworks**: Python, R, SQLite, Biopython, automated CI/CD testing.
